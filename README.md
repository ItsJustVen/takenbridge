# TakenBridge

Minecraft (Paper) side of TakenSMP's Discord bridge. It replaces DiscordSRV and connects to the **TakenSMP Utilities** bot.

- **Build:** every push to `main` builds `TakenBridge.jar` automatically (Actions tab), and the jar is attached to the **Latest build** release.
- **Install:** put `TakenBridge.jar` in the server's `plugins/` folder and restart.
- **Pair:** run `/bridge pair` in Discord, then `takenbridge pair <code>` in the server console.
- **Check:** `takenbridge status` in the console, or `/bridge status` in Discord.

See the "TakenBridge — replacing DiscordSRV" roadmap in the TakenSMP project for the phase plan.
